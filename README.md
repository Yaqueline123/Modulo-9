Proyecto de analítica de datos enfocado en el sector retail. El objetivo principal es construir una base de datos limpia, optimizar vistas transaccionales y generar reportes ejecutivos confiables para la toma de decisiones del equipo comercial.

## 🎯 Objetivos del Proyecto 
* **Modelado y Vistas Base:** Consolidar información de ventas, clientes y productos mediante consultas SQL optimizadas.
* **Auditoría de Calidad de Datos:** Detectar y corregir errores comunes en reportes comerciales (duplicidad por granularidad, mezcla de años, falta de contexto en rankings).
* **Insights Comerciales:** Proveer métricas accionables sobre facturación mensual, ticket promedio y productos estrella.
